## 🍱 GharKaBite

### Full-Stack Local Food Ordering & Meal Subscription Platform

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge\&logo=github)](https://github.com/pauldhrupad/GharKaBite)
[![Live](https://img.shields.io/badge/Live-Demo-22C55E?style=for-the-badge\&logo=vercel\&logoColor=white)](https://gharkabite.vercel.app)

A deployed full-stack food-ordering platform designed for a local home kitchen, supporting customizable meals, customer accounts, subscriptions, payments, delivery validation and owner-side administration.

**Engineering highlights**

* Built with **Next.js 16, React 19, MongoDB, Mongoose and Auth.js**
* Role-based **customer and admin authentication**
* Configurable Thalis with selectable items, add-ons and dynamic pricing
* Daily menu and meal availability management
* Customer cart, checkout and persistent order tracking
* Trial, weekly and monthly meal subscription workflows
* Promo-code system with eligibility and one-use validation
* Manual UPI proof verification and Cash on Delivery workflows
* Server-side price, menu and availability validation during checkout
* MongoDB transactions for critical order operations
* Idempotency protection against duplicate order submissions
* Delivery-radius validation using geocoding and location data
* Cloudinary-based image and payment-proof storage
* Automated testing using **Vitest**
* Production deployment through **Vercel + MongoDB Atlas**

**Tech**

`Next.js` `React` `JavaScript` `MongoDB` `Mongoose` `Auth.js` `Tailwind CSS` `Cloudinary` `Geoapify` `Vitest`

## 👨‍👩‍👧 Co-Parenting Coordinator

### Family Coordination, Custody & Expense Management Platform

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge\&logo=github)](https://github.com/pauldhrupad/co-parenting-coordinator)
[![Live](https://img.shields.io/badge/Live-Demo-0EA5E9?style=for-the-badge\&logo=vercel\&logoColor=white)](https://co-parenting-coordinator.vercel.app)

A full-stack coordination platform designed for separated parents to manage custody schedules, child-related expenses, communication and timestamped family records through a shared workspace.

**Engineering highlights**

* Built a **React 19 + Express 5 + MongoDB** full-stack architecture
* JWT authentication with bcrypt password hashing
* Invitation-based family onboarding connecting two parent accounts
* Month, week, day and agenda custody calendar views
* Custody-event overlap and conflict detection
* Structured custody swap request, approval and rejection workflows
* Expense proposal, approval, dispute and settlement state machine
* Percentage-based expense splitting between parents
* Receipt uploads using **Cloudinary**
* Append-only family messages and decision records
* Immutable-style audit history at API and model layers
* MongoDB transactions synchronizing domain changes with audit records
* SMTP email notifications using **Nodemailer**
* Family history exports in **PDF and CSV**
* Backend unit and integration testing with **Vitest + Supertest**
* MongoDB Memory Server replica-set testing
* **44 backend + 11 frontend automated tests**
* **90.75% backend statement coverage**
* Deployed using **Vercel, Render and MongoDB Atlas**

**Tech**

`React` `Vite` `Node.js` `Express` `MongoDB` `Mongoose` `JWT` `Cloudinary` `Nodemailer` `PDFKit` `Vitest` `Supertest`
